# Roy Business Card

Простой статический сайт-визитка.

## Запуск локально

Открой `index.html` в браузере или запусти локальный сервер:

```bash
npx serve .
```

## Деплой на Vercel

Проект привязан к Vercel. Любой пуш в `main` автоматически обновляет production.

## Структура

- `index.html` — вся страница (HTML + CSS)
